 🍇 Wine Quality Prediction API (MLOps Ready)

Production-ready FastAPI application for predicting wine quality using a trained Random Forest model.

## Features

- **FastAPI Framework**: Modern, fast, asynchronous web framework.
- **MLFlow Integration**: Standard ML model management.
- **Pydantic Validation**: Automatic data validation for inference requests.
- **Dockerized**: Containerized for easy deployment and scalability.
- **CI/CD Pipeline**: Automated testing, building, and deployment to Render.
- **Health Checks**: Comprehensive `/health` endpoint.
- **Environment Variables**: Managed via `.env` file.
- **Logging**: Structured request and error logging.

## Tech Stack

- **Web Framework**: FastAPI
- **ML Model**: Scikit-learn Random Forest
- **Containerization**: Docker
- **Deployment**: Render
- **CI/CD**: GitHub Actions

## Prerequisites

- Python 3.7+
- Docker Desktop
- A GitHub repository with CI/CD configured
